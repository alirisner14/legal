# Legal — On the Rise Digital

The published policies for On the Rise Digital apps, served by GitHub Pages at
<https://alirisner14.github.io/legal/>.

Edit a `.md` file here and the page updates. Keep the front matter at the top
of each file intact — the `permalink` is the public URL, and apps link to it.

Master copies live in the Easy-dlp repository's `legal/` folder. If you change
a document in one place, change it in the other.

**Not published here yet:** the Privacy Policy, Terms of Use and EULA. Each
needs a section written for the specific app before it is true of that app,
and the Privacy Policy also carries an internal note that must be removed
before it goes public.
